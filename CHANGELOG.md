# Changelog - PDFMaster Pro

All notable changes to **PDFMaster Pro** are documented in this file.

## [1.0.0] - 2026-07-28

### Added
- **Core SaaS Architecture**: Next.js 14 App Router client with Express Node.js server.
- **Complete PDF Suite**: 30+ PDF processing client & server tools (Merge, Split, Compress, Rotate, Watermark, Sign, JPG to PDF, AI Summarizer, etc.).
- **Enterprise Auth System**: Real Gmail 6-digit OTP verification, Google & GitHub OAuth triggers, bcrypt password hashing, JWT rotation, and HttpOnly secure cookies.
- **Glassmorphic UI Design**: Dark/Light mode theme system, dual-column navigation, and animated components.
- **Sub-pages & Dashboards**:
  - User Workspace: Overview, My Files, PDF History, Subscription, API Keys, Settings, Profile, Invoices, Trash, Favorites.
  - Admin Portal: Overview, Manage Users, Subscription Plans CMS, Security Audit Logs.
- **Documentation**: Comprehensive `README.md`, `INSTALL.md`, `API.md`, `DEPLOYMENT.md`, `DATABASE.md`, `CONTRIBUTING.md`, and `CHANGELOG.md`.
