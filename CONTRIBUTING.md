# Contributing to PDFMaster Pro

Thank you for your interest in contributing to **PDFMaster Pro**!

## Guidelines
1. Fork the repository `https://github.com/Vishwakarmasuraj333/PDFMaster-Pro`.
2. Create a feature branch: `git checkout -b feat/your-feature-name`.
3. Ensure all TypeScript types compile without errors (`npm run build`).
4. Commit your changes following Semantic Commit Messages:
   - `feat: add new feature`
   - `fix: resolve issue`
   - `docs: update documentation`
5. Open a Pull Request for code review.
